RAB·BIT Help Center

A plain-English guide to every part of the RAB·BIT Verification Workbench. You do not need to be technical to use it.

Start here

The Reports homepage

RAB·BIT opens on Reports with four large choices. Go to Homepage removes the welcome choices so you can read the dashboard. The other three choices open the right workspace and highlight the first step. The smaller workflow buttons remain at the top of Reports whenever you want to begin later.

If you already have an AI answer

Open Fact-check and paste the answer.

Press Extract claims. RAB·BIT breaks the answer into smaller statements that can be checked.

Check each claim against a real source and record the result.

Optionally use Judge & tests, then give the audit a useful name and save it.

If you want RAB·BIT to build the answer

Add trusted information under Grounding.

Use Prompt console to choose the rules for the answer.

Retrieve passages and generate a cited answer.

Send that answer to Fact-check, review it, judge it, and save it.

Important: RAB·BIT helps organize verification. An AI cross-check is a second opinion—not proof. A human still needs to open and read trustworthy sources.

The top bar

Audit name

Replace “Untitled audit” with a name you will recognize later. RAB·BIT requires a real name before saving.

Claims, Cleared, Judge, Verdict

These are live totals for the current audit. They change as claims are reviewed and the judge runs.

Guide

Shows or hides the step-by-step path across the top of the workbench.

Help Center

Opens this complete manual in a separate tab so you do not lose your current work.

Question-mark button

Opens Verity, your RAB·BIT Help Assistant. Verity can answer questions using the page you are on and the current audit status.

Sun and moon

Changes between light and dark mode.

New audit

Clears the current response, claims, and judge results. Save first if you want to keep them.

Save audit

Saves the audit, claims, sources, settings, and scores to the shared Supabase archive.

3

Fact-check

Review an answer / Build an answer / Ask AI

Choose whether you pasted an existing answer, are creating one from trusted evidence, or want to ask a connected AI model inside RAB·BIT.

Ask AI

Type a normal question, then press Choose your AI model. The dropdown shows the OpenAI and Claude models connected to this RAB·BIT deployment. After you choose one, RAB·BIT records the model, generates the answer, copies it into Fact-check, and extracts its claims. The answer is still unverified until you check those claims against trustworthy sources.

AI output to verify

Paste the complete answer you want to check here.

Originating prompt

Optionally record the question that produced the answer. This helps future reviewers understand the context.

Answer source / model

Ask AI fills this in automatically with the model you selected. When you paste an existing answer, choose its source model yourself so reports keep the correct record.

Claim granularity

Coarse creates fewer broad claims. Balanced is the normal choice. Fine creates more small claims for careful review.

Standard of proof

Sets how many source-check boxes are required before a claim can be marked Verified. Three ticks is the strongest standard.

Extract claims

Uses the connected OpenAI model to split the pasted answer into individual factual statements.

Clear

Removes the extracted claims. It does not delete saved audits.

Opinion

Use this when a statement expresses a preference, judgment, prediction, or other subjective view that cannot be proven true or false. It counts as reviewed, but it does not count as a verified fact or require a supporting source.

Suggested searches

Web and Scholar links give you starting points. Prefer official, independent, or primary sources whenever possible.

Source consulted

Paste the URL or citation you actually checked. This creates the evidence trail.

Reviewer note

Write what the source said, what was wrong, or what another reviewer should know.

Claude, ChatGPT, Gemini

These buttons ask another AI to assess the claim. They may expose disagreement, but they do not browse or verify a source and cannot clear a claim.

Source Check boxes

Claim isolated means it can be checked by itself. Citation provided means the answer supplied a citation. Independent source matched means you found separate support.

Claim outcomes

Unverified not decided yet. Verified supported and meets the proof standard. Unsupported you could not find adequate support. Refuted trustworthy evidence contradicts it. Opinion subjective rather than provably true or false.

Add claim manually

Adds a claim if extraction missed something important.

Send to judge

Moves you to Judge & tests with the current answer ready for scoring.

Remove claim

Deletes that claim from the current audit only.

Save audit to archive

Stores the completed record in Supabase so it appears under Saved audits and Reports.

4

Prompt console

Run with

Selects the connected model RAB·BIT will use to generate an answer.

Temperature

Low values make answers more repeatable. High values encourage variety. Keep it low for facts and anything you plan to publish.

Reasoning format

Choose a visible, reviewable structure: direct answer, steps, evidence first, or assumptions and unknowns.

Guardrail switches

Control grounding, citations, uncertainty labels, refusal instead of guessing, scope limits, and structured JSON output.

Compiled prompt

Shows the complete instructions RAB·BIT created from your settings.

Copy prompt

Copies those instructions so you can use them in another AI tool.

Run & send to fact-check

Runs the selected connected model, places its answer in Fact-check, and starts the verification workflow.

5

Grounding

Evidence set

Add policies, approved documents, validated database text, or other trusted material. Paste the actual text—not only a URL.

Add source

Adds another source box. Give each source a useful title and type.

Question

Enter the question the model should answer using only the evidence you supplied.

Passages retrieved

Controls how many matching passages the model may use. Too few may omit useful facts; too many may add noise.

Minimum match

Drops passages that do not match the question closely enough.

Retrieve passages

Searches the pasted source text and shows the best-matching passages and match percentages.

Generate cited answer

Asks the connected model to answer only from the retrieved passages and include RAB·BIT source markers.

Pipeline boxes

The four boxes show progress: sources loaded, passages retrieved, answer generated, and cited answer ready.

Send to fact-check

Copies the generated cited answer into Fact-check. Grounding reduces guessing, but the claims still need human review.

6

Judge & tests

Reference / ground truth

Paste the approved answer or evidence the response should match. Without this, the judge can mainly assess internal quality—not factual agreement.

Rubric

The list of qualities being scored, such as truthfulness and completeness. You can edit the names and descriptions.

Add criterion / Remove

Adds a new scoring requirement or removes one you do not need.

Reset

Restores RAB·BIT’s original four scoring criteria.

Strictness

Changes how hard it is to earn a high score. Strict is appropriate when mistakes could cause real harm.

Pass mark

Sets the required average. A score below this marks the audit “Below bar.”

Run AI judge

Uses a second model to score each rubric item from 1 to 5 and explain the score. The gauges move when results return.

JSON / CSV baseline test

Compares structured model output against known-good data field by field. This is a computer comparison, not an AI opinion.

7

Operations

RAB·BIT Verification Score

A transparent 100-point readiness checklist. It rewards captured answers, extracted claims, completed verdicts, sources, cross-checks, grounding, judge results, and a searchable audit name.

Policy profiles

Standard is the normal workflow. High-stakes applies the strongest settings. Rapid screening is for quick triage, not final approval.

Apply policy

Changes the real proof, granularity, grounding, strictness, and pass-mark settings for the current audit.

Provider health

Shows whether Claude, ChatGPT, Gemini, and Supabase are connected and which model is configured.

Recent service activity

Shows which RAB·BIT operation ran, its status number, and how long it took during the current Render session.

Active alerts

Warns about missing connections, high errors, rate limits, or an audit that is not ready.

Telemetry privacy

Operations records route, status, timing, and provider only. It does not store prompts, answers, claims, API keys, or IP addresses.

Refresh

Checks Supabase for newly saved or deleted audits.

Reports

Summary cards

Show saved audits, claims checked, decision rate, source coverage, judge coverage, and average judge score.

Claim outcomes

Shows how many claims were verified, unsupported, refuted, classified as opinion, or still unverified.

Evidence completion funnel

Shows where review work is dropping off between extracting a claim and verifying it.

Failure by risk and type

Shows whether high-risk claims or certain claim categories fail more often.

Judge rubric averages

Shows which quality criteria score strongest and weakest across saved audits.

Model comparison

Compares how often claims from each answer-producing model fail checking. Larger samples are more meaningful.

Weekly activity and verdicts

Shows audit volume over time and how saved audits finished.

Proof-standard usage

Shows how often reviewers used one-, two-, or three-tick verification.

Recent audits

Shows the newest eight records with verdict, model, claim completion, judge score, and date.

Reviewer discipline

Warns when unsupported or refuted verdicts were saved without recording the source behind the decision.

Refresh

Recalculates the dashboard from the latest Supabase records.

10

Verity

What it can do

Press the question-mark button in RAB·BIT and ask Verity a question naturally. Verity receives this product guide plus a short description of your current panel and audit status. It runs through the OpenAI connection and does not change when you select Claude elsewhere.

Suggested questions

Use the starter buttons, or ask things like “Why can’t I verify this claim?” and “What should I do next?”

What it cannot do

It explains RAB·BIT. It does not click buttons, change the audit, verify sources, or replace your judgment.

Helpful and Not helpful

Rate any completed answer. Verity uses that guidance for later answers during the current visit. If the Supabase feedback table is installed, RAB·BIT also saves the rating for product improvement. This does not automatically retrain OpenAI’s base model.

11

Problems and common errors

Too many requests

RAB·BIT reached a safety limit or an AI provider limit. Wait about one minute and try once more.

Ask AI daily limit

The protected Ask AI path allows 8 questions per minute and 100 per day by default. This protects the site owner’s OpenAI and Anthropic accounts from accidental or unauthorized spending.

Something went wrong

Open Operations and check Provider health and Recent service activity. A red status often contains the useful clue.

Provider not configured

The corresponding API key is missing or invalid in Render. Add or correct it under the service’s Environment settings.

Verity does not answer

Confirm that ChatGPT/OpenAI is connected under Operations. Verity intentionally does not fall back to Claude.

Changes do not appear

Wait for Render to finish deploying, then press Ctrl + Shift + R on Windows to reload without the old cached files.

Render takes a long time

A free Render service sleeps when unused. The first request after a quiet period may take about a minute.

Cannot mark Verified

Complete enough Source Check boxes to meet the selected Standard of proof.

Reports are empty

Reports use saved Supabase audits. Save completed audits first, then press Refresh.

Plain-English glossary

Audit
One saved review of one AI answer.
Claim
One statement classified as verified, unsupported, refuted, opinion, or not yet reviewed.
Citation
A reference supplied with the answer. It still needs to be opened and checked.
Independent source
A trustworthy source separate from the AI answer and its author.
Grounding
Limiting an AI answer to information you supplied.
RAG
Retrieval-Augmented Generation: find relevant passages first, then answer from them.
Rubric
The list of qualities used to grade an answer.
Judge
A second AI model that scores the answer against the rubric.
Policy profile
A reusable bundle of verification settings.
Telemetry
Technical information about whether an operation worked and how long it took.
Supabase
The hosted PostgreSQL database that stores RAB·BIT’s saved audits and reports.
Render
The hosting service that runs the public RAB·BIT website and server.
